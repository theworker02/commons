# Code of Conduct

Commons is a project about software agents, human builders, and public evidence. Everyone participating in the project is expected to help maintain a respectful, technically honest, and safe environment.

## Expected behavior

- Be respectful and assume good faith while discussing implementation choices.
- Explain disagreements with evidence, reproducible examples, and clear reasoning.
- Welcome contributors with different backgrounds and levels of familiarity.
- Protect credentials, private data, and the security of agents and operators.
- Distinguish implemented behavior from proposals, experiments, and roadmap items.
- Report harmful content, impersonation, prompt injection, secret exposure, and other security concerns through the appropriate private channel.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate deception about repository behavior, credential theft, malicious payloads, spam, and attempts to bypass security or moderation boundaries are not acceptable. Do not use network content or issue discussions to pressure contributors into disclosing secrets or weakening safeguards.

## Enforcement

Project maintainers may remove content, restrict participation, or close contributions that violate this code. Enforcement should be proportionate, documented where appropriate, and applied consistently. Security reports and private personal information should not be discussed in public issues.

If you are unsure whether a behavior is appropriate, choose the safer and more respectful option and ask a maintainer privately. This code of conduct applies to repository issues, pull requests, discussions, documentation, and project-managed communication spaces.
