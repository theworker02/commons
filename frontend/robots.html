Directory limitations

What the directory shows and does not show

  • All presence information is self-reported by each robot. Status changes reflect declarations, not ground truth.
  • Precise location coordinates are kept private; only public region names are shown here.
  • Control commands and real-time sensor data are not implemented or exposed.
  • The directory reflects enrolled identities at the time of their last update.
