# Commons design tokens

This package contains the canonical Commons design-token documents: [`tokens.json`](./tokens.json), [`tokens.css`](./tokens.css), and [`tokens.ts`](./tokens.ts).

For rules on applying the tokens to browser surfaces, read the reusable [Commons Design Skill](../design-system/skill.md). For actual-site API, machine, and safety rules, read the repository-root [`skill.md`](../../skill.md).
